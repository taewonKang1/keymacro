================================
 키매크로 - 사용법
================================

[실행 방법]
  '키매크로.exe' 를 더블클릭하세요.
  - 이제 기본적으로 '관리자 권한'으로 실행됩니다.
    실행 시 UAC(사용자 계정 컨트롤) 창이 뜨면 '예'를 누르세요.
  - Python 설치는 필요 없습니다.
  ※ _internal 폴더와 키매크로.exe 는 항상 같이 있어야 합니다.
     폴더 통째로 복사/공유하세요.

[전체 켜고 끄기 - Pause 키]
  - 키보드의 'Pause' 키를 누르면 전체 매크로가 ON/OFF 됩니다.
  - 창 상단에 '● 활성 / ● 비활성' 으로 현재 상태가 표시됩니다.
  - 비활성 상태에서는 아래 두 매크로가 모두 동작하지 않습니다.

[① 연타 매크로]
  - 체크박스 '① 연타 매크로 사용' 으로 켜고 끕니다.
  1) '연타할 키' 옆 [설정] → 연타할 키를 누름
  2) '실행 토글 키' 옆 [설정] → 켜고 끌 키를 누름 (예: Q)
  3) 초당 횟수 조절
  4) 모드 선택
       - 토글        : 토글키를 누르면 ON, 다시 누르면 OFF
       - 누르는 동안만 : 토글키를 누르고 있는 동안만 연타

[② 좌클릭 꾹 누르기 매크로]
  - 체크박스 '② 좌클릭 꾹 누르기 매크로 사용' 으로 켜고 끕니다.
  - '누를 키' 옆 [설정] → 발동 시 눌릴 키를 지정
  - '꾹 누름 시간(초)' → 좌클릭을 이 시간만큼 계속 누르고 있으면
    지정한 키가 '한 번' 눌립니다.
  - 좌클릭을 떼었다가 다시 누르면 시간이 초기화되어 다시 발동할 수 있습니다.
  - 3.9748 ~ 3.9752 어디까지 가능한지는 추가 테스트 필요 3.975부터가 안정권

[설정 저장]
  모든 설정은 exe 옆 config.json 에 자동 저장됩니다.

[백신 경고가 뜰 경우]
  PyInstaller로 만든 프로그램은 백신이 오탐(false positive)할 수 있습니다.
  - "추가 정보" → "실행" 을 누르거나
  - Windows 보안에서 해당 폴더를 예외(허용)로 추가하세요.

[게임에서 입력이 안 들어갈 때]
  이미 관리자 권한으로 실행되므로 대부분 정상 동작합니다.
  그래도 안 되면 게임을 '창 모드'로 실행해 보세요.

[주의]
  - 강력한 안티치트가 있는 일부 경쟁 게임은 차단될 수 있습니다.
  - 온라인 게임은 매크로를 약관으로 금지하는 경우가 많습니다.
    사용에 대한 책임은 사용자 본인에게 있습니다.

## 서비스 1. 엑셀 반복작업, 파이썬으로 버튼 한 번에 끝내드립니다

**한 줄 소개**: 매일·매주 하는 엑셀 합치기, 정리, 집계를 자동 프로그램으로 만들어 드립니다.

**상세 설명**
매달 지점별 엑셀 수십 개를 복사·붙여넣기 하고 계신가요?
파일을 폴더에 넣고 실행만 하면 통합 시트와 요약 시트가 자동으로 만들어지는 프로그램을 제작해 드립니다.

이런 작업이 가능합니다
- 여러 엑셀/CSV 파일 하나로 합치기 (인코딩 깨짐 자동 처리)
- 조건별 합계·평균·건수 요약표 자동 생성
- 중복 제거, 서식 통일, 열 이름 정리
- 매일 같은 양식 보고서 자동 생성
- 실행 파일(.exe)로 만들어 파이썬 없이 더블클릭으로 사용

진행 방식
1. 샘플 파일(민감정보는 가려도 됩니다)과 원하는 결과 형태를 보내주세요
2. 견적·일정 확정 후 작업
3. 결과물 + 사용법 문서 전달, 수정 요청 반영

|---|---|---|---|
| 가격 | 30,000원 | 70,000원 | 150,000원 |
| 내용 | 단순 합치기/정리 1종 | 합치기 + 요약/집계 + 서식 | 복합 업무 자동화 + exe 실행파일 |
| 작업일 | 1일 | 2일 | 4일 |

**FAQ**
- Q. 파이썬을 몰라도 되나요? → A. 네. PREMIUM은 exe 파일로 드리고, 그 외에도 실행 방법을 그림으로 안내해 드립니다.
- Q. 회사 자료라 걱정됩니다 → A. 샘플은 개인정보를 가린 파일이나 가짜 데이터로도 충분합니다. 작업이 끝나면 받은 파일은 삭제합니다.

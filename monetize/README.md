# 수익화 계획: 목표 100만원

## 전략
**파이썬 업무자동화 외주(크몽)를 메인으로 합니다.**
- 개발은 Claude가 하고, 사용자는 계정·결제·고객 메시지 전달만 합니다.
- 초기 비용은 0원입니다.
- 이 레포의 키매크로는 특정 게임용으로 튜닝돼 있어 게임 약관 위반을 부추길 수 있으므로 판매하지 않습니다.

## 목표 수치
| 단계 | 기간 | 목표 |
|---|---|---|
| 1. 첫 리뷰 확보 | 1~2주 | 저가 패키지 3~5건 (약 15~25만원) |
| 2. 가격 인상 | 3~4주 | 리뷰 5개 이후 30~50% 인상, 중가 패키지 위주 (약 40만원) |
| 3. 단골·고가 | 5~8주 | PREMIUM·맞춤 견적 (약 40만원) |
| **합계** | **약 2개월** | **100만원** |

예상치일 뿐 보장된 수익은 아닙니다. 초기 1~2주는 주문이 없을 수 있습니다.
크몽 수수료(판매금액 구간별 약 10~20%)와 세금을 빼면 실수령액은 더 적습니다.

## 사용자가 해야 할 일 (본인 정보가 필요해서 Claude가 대신할 수 없는 일)
1. [ ] **크몽 가입 + 전문가 등록** (kmong.com → 전문가 등록)
   - 본인인증, 정산 계좌 등록
   - 프로필 소개: "파이썬 업무자동화 / 엑셀 / 데이터 수집 전문"
2. [ ] **서비스 3개 등록**: `kmong_listings.md` 내용을 그대로 복사해서 붙여넣기
3. [ ] **포트폴리오 이미지 첨부**: Windows PC에서 `portfolio/` 예제를 실행하고 화면 캡처
4. [ ] (선택) 숨고, 위시켓에도 같은 내용으로 등록
5. [ ] 문의가 오면 **고객 메시지를 Claude 세션에 붙여넣기**. 답장, 견적, 개발, 납품물 작성은 Claude가 합니다.

## Claude가 이미 끝낸 일
- `portfolio/excel_merge/`: 여러 엑셀/CSV 합치기 + 요약 시트 (실행 검증 완료)
- `portfolio/file_organizer/`: 종류별/날짜별 파일 자동 정리, 미리보기 지원 (실행 검증 완료)
- `portfolio/web_scraper/`: 공개 연습 사이트 수집 → 엑셀 저장 (실행 검증 완료, 40건)
- `kmong_listings.md`: 서비스 3개 판매글, 패키지 가격, FAQ
- `message_templates.md`: 문의·견적·납품·거절 응대 문구

## 지키는 원칙
- 개인정보 수집, 로그인 우회, 약관 위반 크롤링, 게임 매크로 판매는 하지 않습니다.
- 가짜 리뷰, 자기 구매, 스팸 홍보는 하지 않습니다.

## 예제 실행 방법
```bash
pip install -r requirements.txt
cd portfolio/excel_merge && python merge_excel.py sample_input 결과.xlsx --group 지점 --sum 매출
cd portfolio/file_organizer && python organize_files.py 정리할폴더 --dry-run
cd portfolio/web_scraper && python scrape_books.py books.xlsx --pages 3
```

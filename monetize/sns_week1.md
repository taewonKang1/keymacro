# 첫 주 SNS·블로그 원고 (스레드/X + 네이버 블로그)

목적은 크몽 "업무자동화" 서비스로 고객을 데려오는 것입니다. 유용한 팁을 먼저 주고, 링크는 끝에 한 번만 겁니다.
`[크몽링크]` 자리에는 서비스를 등록한 뒤 실제 주소를 넣습니다. 광고성 글에는 맨 위에 "광고" 표시를 합니다.

---

## 스레드/X 일일 게시물 (7개)

**Day 1**
엑셀 파일 30개를 하나로 합치느라 오후를 다 날린 적 있나요?
파이썬 15줄이면 폴더에 넣고 실행 한 번으로 끝납니다.
- 파일명은 신경 안 써도 됨
- CSV·XLSX 섞여 있어도 됨
- 한글 깨짐(cp949)도 자동 처리
코드 궁금하면 댓글 주세요. 그대로 드립니다.

**Day 2**
다운로드 폴더가 지옥인 분들께 드리는 팁.
파일을 확장자별로 자동 분류하는 스크립트는 30줄이면 됩니다.
핵심은 '미리보기 모드'예요. 실제로 옮기기 전에 어디로 갈지 먼저 보여주니까 실수할 일이 없습니다.

**Day 3**
매주 같은 양식 보고서 만드는 분들,
"복붙 → 서식 맞추기 → 합계 확인"을 매번 손으로 하면 1년에 50시간이 넘습니다.
자동화의 기준은 간단해요: 같은 일을 세 번 했으면 자동화할 때입니다.

**Day 4**
웹에서 정보 긁어오기(크롤링) 전에 꼭 확인할 3가지
1. 그 사이트의 이용약관
2. robots.txt
3. 공식 API가 있는지
API가 있으면 그게 제일 빠르고 안전합니다. 크롤링은 마지막 수단입니다.

**Day 5**
"파이썬 몰라서 자동화 못 해요"
→ 실행 파일(.exe)로 만들면 더블클릭만 하면 됩니다. 설치도 필요 없어요.
쓰는 사람이 코드를 몰라도 되는 게 좋은 자동화입니다.

**Day 6 (광고)**
[광고] 반복 업무 자동화 프로그램을 만들어 드립니다.
엑셀 합치기·정리, 파일 분류, 웹 데이터 수집 → 버튼 한 번으로.
샘플 파일만 보내주시면 결과 형태를 먼저 보여드립니다.
[크몽링크]

**Day 7**
이번 주 올린 자동화 팁 정리
① 엑셀 여러 개 합치기 ② 폴더 자동 정리 ③ 반복 보고서 ④ 크롤링 전 체크리스트 ⑤ 실행 파일로 배포
어떤 게 제일 필요하세요? 댓글로 알려주시면 다음 주에 자세히 다룰게요.

## 네이버 블로그 글 1: 엑셀 파일 여러 개를 한 번에 합치는 법 (코드 포함)

**제목:** 엑셀 파일 수십 개, 복사·붙여넣기 없이 1분 만에 합치는 법 (파이썬 무료 코드)

1. **이런 분께 필요합니다:** 지점별·월별로 따로 오는 엑셀을 매번 손으로 합치는 분
2. **준비물:** 파이썬 설치, 그리고 `pip install pandas openpyxl`
3. **코드:** `monetize/portfolio/excel_merge/merge_excel.py`의 핵심 부분을 설명과 함께 넣습니다
4. **결과:** 합쳐진 결과 화면과 요약 시트를 캡처해서 넣습니다
5. **자주 막히는 곳:** 한글 깨짐(인코딩), 빈 행, 열 이름이 서로 다를 때
6. **마무리:** "직접 하기 어려우면 맞춤 제작도 해드립니다 → [크몽링크]" (광고 표시)

## 네이버 블로그 글 2: 크롤링, 해도 되는 것과 안 되는 것

**제목:** 웹 크롤링 전에 꼭 알아야 할 법적·기술적 체크리스트 (2026)

1. 이용약관과 robots.txt 확인하는 법
2. 개인정보 수집은 왜 안 되는지
3. 서버에 부담을 주지 않는 요청 간격
4. 공식 API와 공공데이터포털 같은 대안
5. 예제: 연습용 사이트(books.toscrape.com)로 수집해서 엑셀로 저장하기
6. 마무리 문구는 글 1과 같습니다

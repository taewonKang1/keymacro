# 72시간 100만원 스프린트

크몽은 리뷰 없는 신규 판매자에게 주문이 들어오기까지 시간이 걸려서 72시간 안에는 부족합니다.
그래서 **돈이 빨리 들어오는 경로를 동시에** 돌립니다. 모든 결제와 계약은 사용자 명의로 이뤄지고, 작업과 글쓰기는 Claude가 합니다.

## 경로별 예상 (72시간 기준)

| A. 중고거래 (당근마켓·번개장터) | **높음** | 안 쓰는 물건에 따라 다름 | 물건 사진 찍기, 거래 나가기 |

| C. 위시켓·프리모아·이랜서 프로젝트 지원 | 중간~낮음 (계약 후 선금) | 30~100만원/건 | 가입, 지원서 제출, 미팅 |

**현실적인 조합:** A로 기본 금액을 확보하고, B와 C로 외주 1~2건을 따내는 것입니다.

## 시간표
**0~6시간**
- [ ] 집에서 안 쓰는 물건 목록 + 사진 → Claude에게 보내기 (Claude가 시세 조사, 가격, 판매글 작성)
- [ ] 숨고 고수 가입 (분야: IT·개발 → 업무자동화/데이터/웹)
- [ ] 위시켓 또는 프리모아 가입

**6~24시간**
- [ ] 중고 판매글 등록 (Claude 작성본 붙여넣기)
- [ ] 숨고에 들어온 요청서와 위시켓 공고를 Claude에게 복사해서 전달 → Claude가 맞춤 견적·지원서 작성
- [ ] 크몽 서비스 3개 등록 (장기 수익용)

**24~72시간**
- [ ] 계약된 작업을 Claude가 개발 → 사용자가 납품
- [ ] 중고 거래 진행, 안 팔리면 Claude가 가격 조정안 제시

## 하지 않는 것
가짜 리뷰, 자기 구매, 스팸 홍보, 약관 위반 크롤링, 게임 매크로 판매, 도박·고위험 투자, 클라우드 자원으로 채굴.

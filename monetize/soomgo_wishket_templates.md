# 숨고 · 위시켓 등록/지원 문구

## 숨고 고수 프로필
**서비스:** IT·개발 → 업무 자동화, 데이터 수집, 엑셀 VBA·파이썬
**한 줄 소개:** 반복 업무를 버튼 한 번으로. 엑셀·파일·웹 데이터 자동화를 빠르게 만들어 드립니다.
**상세 소개:**
매일 반복하는 엑셀 정리, 파일 분류, 웹 정보 수집을 자동 프로그램으로 만들어 드립니다.
- 간단한 작업은 당일, 대부분 2~3일 안에 납품합니다
- 파이썬을 몰라도 더블클릭으로 쓰는 실행 파일(.exe)을 제공합니다
- 납품 후 수정 요청도 반영합니다
- 개인정보 수집, 약관 위반 크롤링은 하지 않습니다

말씀하신 [작업 요약]은 [N]일 안에 [금액]원으로 진행할 수 있습니다.
샘플 파일을 하나 보내주시면 결과 형태를 미리 보여드리고 시작하겠습니다.
비슷한 작업 예시: 지점별 엑셀 여러 개 → 통합 시트 + 지점별 매출 요약 자동 생성

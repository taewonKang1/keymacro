# 키매크로

키 연타 + 좌클릭 꾹 누르기 매크로 (Windows 전용)

순수 표준 라이브러리(`ctypes` + `tkinter`)만 사용하며, 관리자 권한으로 실행됩니다.

## 기능
- **① 연타 매크로 (F1)** — 지정한 키를 초당 원하는 횟수로 연타. 토글 / 누르는 동안만 모드 지원.
- **② 좌클릭 꾹 누르기 매크로 (F2)** — 좌클릭을 설정한 시간만큼 유지하면 지정 키가 한 번 입력됨.
- 실시간 작동 로그, 설정 자동 저장(`config.json`).

## 단축키
- `F1` = ① 연타 매크로 켜기/끄기
- `F2` = ② 꾹누름 매크로 켜기/끄기

## 실행 방법
### 1) 빌드된 실행 파일
`키매크로.exe` 를 더블클릭하세요. (`_internal` 폴더와 항상 같이 있어야 함)
Python 설치는 필요 없습니다.

### 2) 소스로 실행
```bash
python 키매크로.py
```
Windows + Python 3 필요. 실행 시 관리자 권한(UAC)을 요청합니다.

## 소스에서 빌드 (PyInstaller)
```bash
pyinstaller --windowed --uac-admin --name 키매크로 키매크로.py
```
